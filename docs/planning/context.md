# MAIN CONTEXT

This is the main context file for overview of the project.

This work will be based on my Master thesis "Automatic Generation of DRI-Statements", however, we will need to make many improvements to make this a proper scientific contribution. We will generalize the method for concourse generation and build a robust pipeline for reproducibility. We validate test that pipeline across at least 3 sufficiently different cases. We will present the work at CompText conference and submit to EMNLP conference for peer reviewed publication.
